# 产品范围纠正记录

## 结论

此前实现的 `OpenTV API21` 是 IPTV/M3U 直播播放器，采用频道、播放列表和流地址导入模型，**不符合**用户指定的第三方抖音电视客户端目标。本实现不再作为最终产品交付。

经用户提供的仓库截图确认，唯一正式参照为 [`mytv-android/mytv-android`](https://github.com/mytv-android/mytv-android) 的 **myDV**，截图显示其当前稳定版本为 `V1.2.22`。此前检索到的其他同类仓库不是本项目参照，不得用来定义功能或架构。

## 需要复刻的目标能力

| 能力 | 目标说明 |
|---|---|
| 抖音网页呈现 | 加载官方抖音网页，不实现第三方内容抓取或绕过登录机制 |
| TV 遥控器 | 上下切换、左右滚动、确认播放/暂停、返回导航、菜单动作 |
| 会话延续 | 仅使用 Android WebView 正常 Cookie 存储保留已登录状态 |
| 大屏播放 | 横向大屏布局、硬件加速、视频结束后的下一内容导航 |
| API 21 兼容 | 保持 `minSdk 21`，避免使用高版本系统专属 API |

## 约束

本项目只重建公开描述的客户端交互，使用官方网页路径，不包含账号凭据、不破解 DRM、不规避平台限制，也不嵌入或分发受版权保护的视频内容。
